# Sales Analytics Dashboard

## 📊 Project Overview

This project is an interactive **Sales Analytics Dashboard** designed to
analyze sales performance, profitability, product categories, regions,
states, and time-based trends.

The dashboard provides a clear executive-level view of business
performance while also allowing users to drill down into categories,
regions, segments, and individual sub-categories through interactive
filters.

The project is designed as a **Business Intelligence / Data Analysis
project**, with a focus on:

-   Sales performance analysis
-   Profitability analysis
-   Category and sub-category analysis
-   Regional performance
-   State-level performance
-   Monthly and yearly trends
-   Interactive filtering
-   Dashboard navigation
-   Source-data exploration

------------------------------------------------------------------------

## 🎯 Project Objectives

The main objectives of the dashboard are to:

1.  Monitor total sales and profit.
2.  Understand how different product categories contribute to sales.
3.  Compare sales performance across regions and states.
4.  Analyze quantity sold by sub-category.
5.  Identify monthly and yearly sales trends.
6.  Allow users to filter the analysis dynamically.
7.  Present business data in an interactive and visually understandable
    format.
8.  Provide separate analytical views for sales, categories, and
    regions.

# 🧩 Dashboard Interactivity

The dashboard is designed around interactive filtering.

For example:

**Category → Sub-Category → Region → Year**

Changing a filter updates the connected visuals and KPI values according
to the selected context.

This allows users to answer questions such as:

-   How much did a specific category sell?
-   Which sub-category has the highest quantity?
-   How do sales differ between regions?
-   How did sales change from 2016 to 2019?
-   Which states generate the largest sales?
-   How does profit change over time?
-   What happens to the dashboard when a particular segment is selected?

# 📌 Example Analysis Workflow

A typical analysis session can follow these steps:

### Step 1 --- Start from Home

Open the Home Page and choose the required dashboard.

### Step 2 --- Review KPIs

Check total sales, profit, or quantity.

### Step 3 --- Analyze Categories

Use the Category Dashboard to compare categories and sub-categories.

### Step 4 --- Analyze Geography

Use regional and state-level charts to identify geographic differences.

### Step 5 --- Analyze Trends

Review monthly and yearly trend charts.

### Step 6 --- Apply Filters

Use slicers to focus on:

-   A specific category
-   A specific year
-   A specific region
-   A specific segment
-   A specific sub-category

### Step 7 --- Compare Results

Observe how the KPIs and charts change based on the selected filters.
